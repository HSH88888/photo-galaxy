# 📷 Photo Galaxy (Windows / Web)

수만 장의 사진을 **방사형 폴더 트리 + 해바라기 나선(Phyllotaxis) 배치 + 시맨틱 줌(Semantic Zoom)**으로 한눈에 탐색하는 나만의 은하수 사진 뷰어입니다.

## ✨ 주요 기능
- **은하수 방사형(벌룬) 레이아웃**: 하위 사진 수에 비례하는 폴더 대표 사진 원과 주변 나선형 사진 배치
- **시맨틱 줌 & 130장 임계값 최적화**:
  - 멀리서 볼 때는 부드러운 은하수 링과 점으로 고속 렌더링
  - 화면에 보이는 사진이 **130장 이하**(상단 `🖼️ 130장` 버튼에서 `20~500장` 조절 가능)로 확대되면 즉시 JPEG 내장 EXIF 썸네일 → 512px → 1600px 고화질 이미지로 전환
- **분류 기준 전환 (`폴더별` | `연·월별` | `일별`)**: 실제 폴더 구조뿐 아니라 촬영/수정 날짜 기준으로도 즉시 전환
- **전체화면 뷰어**: 사진 클릭 시 크게 보기, `←` / `→` 키 또는 마우스 휠로 이전·다음 사진 탐색, 원본 파일 열기
- **전용 윈도우 앱 (`PhotoGalaxy.exe`)**: 브라우저 주소창 없는 독립 실행 파일 및 `📁 폴더` 선택 대화상자 지원

## 🚀 실행 방법

### 1. 윈도우 실행 파일로 바로 실행
- `PhotoGalaxy.exe` 또는 `run.bat` 더블클릭

### 2. 파이썬 소스로 실행
```bash
pip install Pillow pywebview
python app.py        # 전용 윈도우 앱 창으로 실행
# 또는
python server.py     # 웹 브라우저(http://127.0.0.1:8765)로 실행
```
